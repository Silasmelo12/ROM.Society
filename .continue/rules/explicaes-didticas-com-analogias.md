description: Usar quando o usuário pedir explicações simplificadas, didáticas ou
  com analogias, ou quando eu perceber que o tema é complexo e merece uma
  abordagem mais acessível.
alwaysApply: false
---

Ao explicar conceitos técnicos complexos, use linguagem simples, acessível e didática. Prefira analogias do mundo real (ex: carteira de identidade para JWT claims, filtro de café para SecurityFilter, etc.). Evite jargão técnico sem contexto. Explique como se estivesse ensinando alguém que não é especialista no assunto, mas sem ser condescendente. Sempre conecte o conceito abstrato a algo concreto que o usuário já conhece do dia a dia.
